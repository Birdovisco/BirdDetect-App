# BirdDetect App

Repository for BirdDetect application

## Setup

Node.js version > 19 is required
This project uses yarn for package management

## Download dependecies

In project directory run command

```yarn```

## Aplication build

Download the [.apk](https://expo.dev/accounts/itguy12345678/projects/SigmaBirder/builds/0de06e9b-3571-42e2-b9f7-5d91bf85e49c) file on your mobile Android device and install it.

## Expo Go

Install the 51 SDK version of [Expo Go](https://expo.dev/go?sdkVersion=51&platform=android&device=true) app on your Android phone and connect to the same wireless network as your computer.

## Run

In project directory run command

```yarn expo start```

On your mobile device, open the Expo Go app and scan the QR code from the terminal or enter the application URL manually.
